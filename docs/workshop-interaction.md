# 网页壁纸交互与播放方式

## 操作

已下载且项目类型为 `web` 的工坊壁纸可进入交互模式。入口在详情手形按钮、右键菜单、顶部 LIVE 菜单、系统「动态壁纸」菜单以及菜单栏图标菜单；系统菜单快捷键为 Command–Shift–I。

交互时临时将当前桌面壁纸窗口放到普通窗口层，交给原生 WKWebView 接收点击、按下 / 抬起、拖拽、滚轮和键盘。右上角显示退出提示。按 Esc 或点「退出交互」后释放键盘焦点，将窗口放回桌面层并恢复鼠标穿透；保持同一个网页实例，已选择的当前播放方式不会因退出交互而被重新加载。

切到其他 App、切换壁纸、停止壁纸、显示器配置变化或系统休眠时退出交互；交互期间不让播放列表自动切换壁纸。网页本身的默认定格、循环及其他选项仍遵循作者实现。这里不承诺网页内部设置能跨 App 重启保存。

## 转换开关

「下载后自动转为视频」关闭时：

- 桌面、工坊详情和大图预览（含播放列表预览）都使用源文件。
- 正在播放转换视频的桌面重新加载源文件；已有转换视频不删除。
- 自动转换停止，等待队列保留；即使手动生成视频，也不会在开关关闭时选用它播放。
- 原生视频壁纸始终播放原始视频，不受此开关影响。

开启后允许使用仍有效的转换视频。显式进入网页交互会回到源网页，并在退出交互后保留当前网页实例；重新应用壁纸时按开关选择播放方式。

## 验证范围

完整单元测试 185 项通过；Apple 芯片与 Intel 的通用 Release 构建及签名校验通过，最低系统要求保持 macOS 14.0。回归用例覆盖关闭开关不读取转换缓存、原生视频不受开关影响、桌面窗口输入与键盘焦点的进入 / 恢复、网页视图 hitTest、停止后不能重新启用输入，以及场景壁纸不误用网页交互。真实 FRAC 的完整点击和循环播放仍需运行新版后验收；本轮没有改动其下载文件或网页内部脚本。
