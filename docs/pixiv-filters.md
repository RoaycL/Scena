# Pixiv 筛选与会话

## 筛选范围

无搜索词时浏览榜单，有搜索词时使用关键词搜索。两者分别显示实际可用的筛选条件。

| 模式 | 条件 | 说明 |
| --- | --- | --- |
| 榜单 | 日、周、月、新人、原创、AI、男性向、女性向 | 综合榜不发送不适用的作品类型参数 |
| 榜单 | R-18 日、周、AI、男性向、女性向，以及 R-18G | 需要已验证的 Pixiv 登录；官网账号必须允许相应内容 |
| 榜单 | 全部、插画、漫画、动图封面 | 月榜和新人榜不显示动图；综合榜隐藏类型筛选 |
| 榜单 | 历史日期 | 日本时间，最晚昨天，`date=YYYYMMDD` |
| 搜索 | 全年龄、全部、R-18 / R-18G | 默认全年龄，受限内容需要登录；按官网 `mode=safe/all/r18` 查询 |
| 搜索 | 全部、插画、漫画、动图封面 | 分别使用 artworks、illustrations、manga 接口；动图通过 illustrations 查询 |
| 搜索 | 标签部分一致、标签完全一致、标题和说明 | `s_mode=s_tag/s_tag_full/s_tc` |
| 搜索 | 最新、最旧 | `order=date_d/date` |
| 搜索 | 热门、男性热门、女性热门 | 需要登录及 Pixiv 高级会员；服务端拒绝时明确提示会员权限，不视为空列表 |
| 搜索 | 横图、竖图、正方形 | `ratio=0.5/-0.5/0` |
| 搜索 | AI 显示或隐藏 | 隐藏时发送 `ai_type=1`；显示时仍遵循官网账号设置 |
| 搜索 | 投稿日期范围 | `scd/ecd`，提供最近 7 天、30 天、一年及自选日期 |
| 搜索 | 宽高上下限 | `wlt/wgt/hlt/hgt`，单位像素，留空或 0 不限制 |
| 搜索 | 收藏数上下限 | `blt/bgt`，需要登录及高级会员 |
| 搜索 | 创作工具 | `tool`，可填写 Photoshop、SAI、CLIP STUDIO PAINT 等 |

输入条件与每个图源的既有偏好共用持久化机制。登录验证成功时恢复已保存的受限筛选；退出后清理当前受限选项并重新搜索全年龄内容。Pixiv 与 Wallhaven 的登录权限分别判断，Wallhaven 登录不能解锁 Pixiv 条件。账号 Cookie 不进入筛选快照或偏好数据。

Pixiv 搜索没有独立的 R-18G 请求模式，R-18 / R-18G 合并按官网受限模式查询；单独的 R-18G 榜单使用 `mode=r18g`。不绕过官网年龄、内容显示或会员限制。静态封面不等同于 ugoira 动画播放，漫画目前不整本下载。

## 会话持久化

- Pixiv：验证后的 PHPSESSID 保存在系统钥匙串；独立的持久 WebKit 资料保留浏览器状态。启动后重新验证，不在验证前发布已登录状态。保存失败时明确提示临时登录。
- Cloudflare：原请求探测通过后才将具备原始域名、路径、HTTPS 与过期时间的 Cookie 保存到系统钥匙串（旧版本存在偏好设置中的记录会在启动时迁移并删除）。验证窗口使用独立的持久网页资料，不与 Steam 网页登录共享。重启恢复仍有效的记录；本地还限制最长复用 24 小时。站点可以提前撤销验证，持久保存不代表永久有效。

## 验证边界

使用未登录、全年龄的真实公开请求验证了全部作品与漫画的响应结构、最新/最旧及匹配方式、宽高、画幅和隐藏 AI 参数。单元测试使用假账号和隔离存储，覆盖参数编码、内容分级、登录解锁与退出回退、偏好恢复及 Cloudflare 验证保存后重建存储复用。

真实账号下的受限榜单、年龄显示权限、会员热门排序、收藏数范围与重启登录仍需要用户验收。Web JSON 接口未有稳定性保证，站点修改后需要复核。
