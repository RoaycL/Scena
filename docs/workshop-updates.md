# 工坊内容更新

## 使用

- 创意工坊和资料库顶栏的更新菜单：检查更新、更新全部；没有版本记录的条目单独提供「校验旧记录」。
- 工坊详情、右键菜单：更新指定壁纸；已是最新的条目也可手动校验。
- 设置 → 创意工坊：开启自动更新。默认关闭；应用启动及每 30 分钟检查一次，应用退出时不再检查。
- 下载管理：沿用单项与整组暂停、恢复、停止。更新中的已完成旧任务会重新显示在进行中区域。

## 版本与兼容

远程详情保留 `time_updated` 和可用的 `hcontent_file`。Steam CDN 组件在下载完成时返回实际使用的清单 ID 和更新时间，和本地完整文件记录一同保存；不会用下载完成后才查到的新版本冒充已下载版本。SteamCMD 下载保守使用下载前的公开详情快照，获取不到版本时保留为待校验；作者在下载期间再次更新时，可能需要再检查一次。

旧文件记录、收藏和资料库索引兼容读取。没有远程版本记录，或本地文件已被修改的条目显示待校验，不猜测本地创建时间代表作者版本。原文件不因检查而改动。无权限、下架、隐藏或缺少版本元数据的条目不显示为最新；手动检查会统计无法获取版本的数量。

可识别工坊 ID 的导入内容可以检查更新；更新写入 App 的工坊下载目录，导入的原文件夹不覆盖。自动更新和「更新全部」只处理确认有新版的条目；旧记录待校验项不会自动加入队列，需要显式选择「校验旧记录」或校验单项。自动更新不恢复用户暂停、失败、停止的任务；手动批量操作保留暂停中的任务，单项恢复由用户操作。

## 安装与缓存

Steam CDN 按清单在暂存目录校验并复用旧文件，完整后换入。SteamCMD 更新批次使用独立安装目录，明确成功后才将完整条目移入 App 资料库；安装换入失败时回退旧目录。失败或暂停不删除旧版，停止仅丢弃暂存文件。更新检查不改变桌面选择；安装成功仅重新加载正在播放的同一工坊条目。

出现在下载队列中代表正在执行下载或校验任务，不代表完整重下。Steam CDN 会复用大小及哈希一致的旧文件，下载缺失或发生变化的内容；读取远程清单仍需联网。

安装后失效本地索引及旧烘焙结果，文件版本进入预览缓存键，同一路径的视频和场景预览会重新创建。更新后可按自动转换设置重新烘焙。

## 验证

完整单元测试 189 项通过；Apple 芯片与 Intel 的 Release 构建及应用 / Steam 组件签名校验通过，最低系统要求保持 macOS 14.0。回归测试覆盖版本比较、超大清单 ID、旧数据解码、更新任务重启与批次中断、版本未知的旧记录不自动入队、自动更新尊重暂停 / 失败 / 停止、文件被修改与条目不可用、安装失败回退以及下载组件返回实际版本。真实账号的作者更新、Steam CDN / SteamCMD 下载及实际桌面播放仍需端到端验收。
